# TGUH wrapper

Wraps the `breakfast` package for Tail-Greedy Unbalanced-Haar detection,
with information-criterion model selection.

## Usage

``` r
tguh_wrapper(x, ...)
```

## Arguments

- x:

  A numeric vector.

- ...:

  Additional arguments passed to
  [`breakfast::breakfast()`](https://rdrr.io/pkg/breakfast/man/breakfast.html).

## Value

A `ggcpt` object.

res$changepoints
#> # A tibble: 1 × 2
#>      cp cp_value
#>   <int>    <dbl>
#> 1    60   -0.999
res$penalty$type
#> [1] "sSIC"
